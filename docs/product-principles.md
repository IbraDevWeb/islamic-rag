# Principes produit

## Mission

Permettre à un utilisateur de consulter les positions textuellement attestées
d'autorités savantes plutôt que de recevoir une opinion générée par une IA.

## Public

- grand public musulman ;
- étudiants cherchant des sources textuelles.

## Langues

- français ;
- arabe ;
- anglais prévu ultérieurement.

## Périmètre initial

Tradition sunnite classique :

- hanafite ;
- malikite ;
- shaféite ;
- hanbalite ;
- zahirite.

## Réponse

Une réponse doit pouvoir distinguer :

- position d'une école ;
- divergences internes ;
- qualification (`mashhur`, `rajih`, etc.) uniquement si attestée ;
- position personnelle d'un auteur ;
- opinion rapportée par un auteur ;
- sources classiques et sources contemporaines.

## Interdictions

Le système ne doit pas :

- déduire seul une règle à partir du Coran ou d'un hadith ;
- attribuer une parole à Allah ou au Prophète sans source textuelle ;
- inventer une référence ;
- transformer une absence de divergence retrouvée en consensus ;
- présenter la fréquence des résultats comme preuve d'une position majoritaire.
